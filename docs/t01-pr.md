# T01：验证 150 节点画布的交互与性能

新增 `/poc/canvas`，用 React Flow + Yjs 承载 100 个视频、30 个图片、20 个文本节点和 150 条连线。视口外节点不渲染，缩放低于 0.4 时简化为标题卡片；悬停/选中才申请视频名额，全局最多挂载和播放四个视频。拖动、选择、视口变化及重置统一进入命令层。

提供五段可复现的本地 720p 样片、可见窗口鼠标/滚轮测量脚本、页面指标与 JSON 导出。没有业务接口或持久化，刷新后重置。

## 验证

- lint、typecheck、11 项 Vitest 测试通过，覆盖 Yjs 数据回读、四播放器名额与卡顿帧计数。
- Chrome、Edge 对更新后的 Docker 站点各通过 4 项 Playwright 测试，要求真实数据库、Redis、NAS 健康；检查 50 个节点真实框选后同位移拖动、720p 视频解码、播放器上限与简化模式卸载。
- 当前机器三轮 production 实测：首屏 111.3～139.3 ms；平移/缩放约 180 FPS；组拖动平均 177.0～179.8 FPS；视频峰值 4。完整环境、内存与限制见 docs/poc-canvas.md，原始数据随仓库提交。
